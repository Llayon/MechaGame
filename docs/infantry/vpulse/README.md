# V‑Pulse на полигоне MechaGame

Открой [полигон с V‑Pulse](http://127.0.0.1:3000/?demo=infantry&kit=vpulse). В меню экипировки можно переключиться на вариант без оружия, выбрать клип, поставить его на паузу и пройти по фазам. В режиме «Игровое управление» клавиша `F` показывает выстрел с места. Массовая сцена открывается по [отдельной ссылке](http://127.0.0.1:3000/?lab=infantry&kit=vpulse).

| Ассет | Треугольники | Материал | Размер GLB |
|---|---:|---|---:|
| [V‑Pulse для полигона](../../../public/assets/infantry-vpulse/v-pulse.glb) | 3 702 | PBR, четыре карты 512×256 | 239 412 Б |
| [V‑Pulse для массовки](../../../public/assets/infantry-vpulse/v-pulse-crowd.glb) | 458 | PBR с цветами вершин | 31 492 Б |

Модель получена из пользовательского HTML. Генератор сохраняет форму корпуса, ручку, приклад и контрастную полосу. В крупном LOD также сохраняются подписи и основные мелкие детали. Панели и приклад экспортируются в исходном положении. Оба GLB имеют длину около 0,22 игровой единицы и одинаковые локальные точки `grip_right`, `grip_left`, `muzzle`. [Параметры экспорта](../../../public/assets/infantry-vpulse/manifest.json)

[Рендер крупной версии](images/rifle-close.png) · [Рендер массовой версии](images/rifle-crowd.png)

Полигон использует три геометрических LOD солдата и один активный `AnimationMixer`. Ближний GLB оружия общий для LOD 3999 и 1999, облегчённый используется с LOD 999. Винтовка крепится к `hand_R` по transform из манифеста. Точка `grip_left` определяет опору левой ладони. Вспышка привязана к `muzzle` и времени в клипе отдачи. Это демонстрация внешнего вида и анимации.

В GPU-стенде тело и винтовка читают один атлас, фазу и матрицу каждого экземпляра. Винтовка использует только матрицу `hand_R`, с весом 1.0 ко всей модели. Тело и винтовка имеют по одному материалу и делят данные экземпляров в каждом батче. Это два вызова на видимый батч за проход пехоты. Цветовой и теневой проходы берут одну позу. Для 200 фигур тело и оружие составляют 291 400 треугольников за проход при полной видимости, до уровня сцены и теней.

В Blender-проекте сохранены редактируемый Rigify, вооружённые клипы и примерка. `Rifle Aiming Idle`, `Rifle Walk` и `Firing Rifle` задают движение верхней части тела. Нижняя часть тела опирается на существующие клипы Mixamo. Для бега, приседа, движения в приседе, прыжка и стойки на колене поставлен двуручный хват поверх этих же клипов. К кадру вспышки на 0,133 с винтовка поднимается почти горизонтально. Скрипт решает обе руки в Blender и записывает результат в GLB и в атлас **36×428 RGBA16F**, 123 264 байта. [Blender-проект](../../../public/assets/infantry-armed/infantry-vpulse.blend) · [Манифест движений](../../../public/assets/infantry-armed/manifest.json) · [Рендер хвата](blender/fire-support.png)

Проверены все 428 кадров для трёх LOD. Максимальная разница между точкой опоры и центром левой ладони в GLB составляет 0,0000041 игровой единицы на запечённых кадрах. В браузере проверено по 120 поз в Chrome и Edge, включая все клипы, крепление и длину винтовки во всех LOD. При смешивании ожидания и бега отмечен сдвиг ладони до 0,0043 игровой единицы, около 1,6 см. Пальцы остаются частью жёсткой геометрии перчатки. Присед сохраняет глубокую защитную стойку из текущего набора. [Проверка GLB и атласа](../../../public/assets/infantry-armed/rig-verification.json) · [Chrome](demo-chrome.json) · [Edge](demo-edge.json)

Управление, смена экипировки и один импульс по `F` пройдены в обоих браузерах. Сборка Vite, TypeScript и 154 теста прошли. [Видео полигона](vpulse-demo.mp4) · [Вспышка в браузере](images/demo-fire.png)

Результаты производительности относятся к изолированной сцене. Для реального смартфона отдельный замер ещё впереди. [Отчёт GPU-стенда](../benchmarks/vpulse/README.md)

Из корня репозитория исходную модель можно пересобрать командой `node scripts/infantry/vpulse_build.mjs <путь-к-HTML>`. Для повторного переноса движений нужен Blender 5.2 с Rigify и винтовочные FBX из папки `Assets` или подготовленный кэш. Использовать `blender --background --factory-startup --threads 1 --python-exit-code 1 --python scripts/infantry/build_armed_rigify.py -- <путь-к-Assets>`. Готовые ассеты входят в репозиторий. Для запуска достаточно сборки Vite и сервера `npm run preview`.
