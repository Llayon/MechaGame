# Исходный пехотинец и исправление бега

Откройте [полигон с исходной моделью](http://localhost:3000/?demo=infantry&kit=vpulse&lod=source). В меню «Детализация» можно переключаться между 40 000, 3999, 1999 и 999 треугольниками. Выберите «Бег» и поставьте анимацию на паузу, чтобы сравнить модели в одной фазе. В режиме управления за бег отвечает **W**.

У исходной модели 40 000 треугольников и две оригинальные PBR-текстуры 2048 × 2048. Сетка и UV сохранены. В Blender доступен Rigify со 146 костями, включая управляющие и служебные. GLB использует 18 костей и восемь клипов. Каждый канал анимации совпадает с вооружённым LOD 999. На исходной модели рельеф задают нормали сетки. Упрощённые версии дополнительно используют запечённую карту нормалей.

При переносе Run из Mixamo кадровая коррекция контакта с землёй местами поднимала корневую кость почти на 9 см. После правки она остаётся на месте, а движение таза сохраняется со сглаженной вертикальной составляющей. Пиковое вертикальное ускорение таза на ключах 30 Гц снизилось с 25,51 до 7,24 игровой единицы в секунду в квадрате. Максимальная разница положения голеностопа между старой и новой версиями при проверке с частотой 120 Гц составила 6,5 мм. Длительность цикла составляет 0,7 с.

В вариантах без оружия убран скачок правого предплечья примерно на 5° в конце цикла. Все остальные клипы совпадают с предыдущей сборкой на ключевых кадрах. Дополнительно пересчитаны ключи ног для контакта подошвы с полом между кадрами. Промежуточные фазы всех 13 GLB и GPU-атласа проверены отдельно. На исходной модели ближайшая точка подошвы оказалась на 0,22 мм выше пола при замере с частотой 960 Гц. [Замеры и пересборка Run](run-polish.md).

В игровом режиме переходы между действиями теперь продолжаются с уже смешанной позы, если быстро отпустить и снова нажать движение. Проверки Chrome и Edge покрывают запуск бега с клавиатуры, несколько циклов, возвращение в стойку и переключение детализации в фиксированной фазе. Отклонение хватки левой руки проверено на всех 428 ключевых кадрах. [Chrome](browser-chrome.json), [Edge](browser-edge.json).

Исходная сетка загружается по запросу для одиночного полигона. Массовый GPU-стенд использует лёгкую геометрию и обновлённый атлас. Зазубренные края наплечников исходной сетки сохраняются при крупном плане. [Проверка GPU-стенда на 20, 100 и 200 экземплярах](gpu-smoke.json).

## Воспроизведение

Запустите скрипты из корня репозитория. Rigify должен быть доступен в Blender 5.2.

```powershell
& 'D:\Programms\Blender Foundation\Blender 5.2\blender.exe' --background --factory-startup --python-exit-code 1 --python scripts/infantry/build_high_rig.py
& 'D:\Programms\Blender Foundation\Blender 5.2\blender.exe' --background --factory-startup --python-exit-code 1 --python scripts/infantry/build_high_rig_review.py
npm run build
npm run preview -- --port 3000
```

Для повторной записи сравнения сначала выполните `node scripts/infantry/source_rig_review.mjs --before` на сборке коммита `b7f84fb`, затем пересоберите текущую версию и запустите `node scripts/infantry/source_rig_review.mjs`. Для проверки Edge используйте флаг `--edge`. Скрипт собирает ролик из стоп-кадров одним ракурсом, замедляя движение вдвое.
